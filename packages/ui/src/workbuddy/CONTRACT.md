# WorkBuddy 设置和用量

组件只通过 hook 调用 ProviderSettingsService.workbuddy；status 仅读 Host 文件投影。
渠道以 providerId 隔离，切换或卸载后忽略旧异步结果，授权轮询按 loginId 防止串号。
运行用量按 x-session-id 聚合，取生成响应 usage.credit，余额查询不参与用量计算。
实时表示上游报告后更新；上游不报告时显示未知，不用模型倍数推断金额。
模型详情与菜单通过同一账号 Hook 读取目录；名称、标签、倍数和详情取上游投影，缺失值不推断。菜单打开刷新忙闲，普通轮询不访问上游。悬停、键盘及窄屏点击详情均可读，不触发模型选择。仅多档模型展示思考调节。
活动由账号目录投影与本地时钟派生，边界/焦点恢复重算；渠道切换开关通过同一 hook 命令保存。登录导出仅显式请求后写剪贴板，不保留在状态；导入粘贴文本，成功清空，错误不回显凭据。
